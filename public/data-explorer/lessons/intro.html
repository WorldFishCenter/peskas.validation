Welcome — your first look at the data

What is R?

When you collect fisheries data, you need a way to make sense of it: to add up catches, compare landing sites, or spot a month when something looks wrong. R is a free tool made for exactly this.

Think of R as a careful, very fast assistant. You give it a short written instruction — “add up the weight”, “show me only the landings from Vanga” — and it does the work exactly and straight away, whether you have ten records or one hundred thousand. It is the same tool used by the scientists who prepare your data.

A spreadsheet like Excel is fine for a small table. R goes further: it does not slow down with large amounts of data, it does not make copy-and-paste mistakes, and it remembers every step — so the same work can be repeated next month without starting over.

What is this page, then?

This page runs R right inside your web browser. There is nothing to download or install — it just works, and it is free.

You do not need to be a programmer. In these lessons you will mostly press a button and change a few small things. And you cannot break anything: if something looks wrong, just press Run again.

Now you try: press Run yourself

This box adds up all the weights. Press the ▶ Run button to see the answer.

What you should see: 44 — the total weight of all six catches, in kilograms.

Change one thing, then run again

You do not need to understand the instruction below yet — that comes in the next lessons. For now, just see how easy it is to change an answer.

This box shows only the catches heavier than 5 kg. Change the 5 to 9, then press Run again.

Try it: with 5 you see four rows. Change it to 9 and press Run — now you see only the two catches above 9 kg. That is all “coding” is here: small instructions you can change, with the answer right away.

This works on YOUR data too

The table above was made up. In the next lessons the table will be your real landing records — the same data you can open in Data Download, from your own sites.

Here is a peek. Press Run to load the first rows of your data:

// Fetch the signed-in user's capped, permission-filtered landings as JSON, reusing the API base URL
// the React app publishes to localStorage (getApiBaseUrl). Same bridge as before: behaves like the
// Data Download tab in dev (-> :3001) and prod (-> /api).
landings_data = {
  const token = localStorage.getItem("authToken");
  if (!token) return [];
  const apiBase = localStorage.getItem("apiBaseUrl") || "/api";
  const res = await fetch(`${apiBase}/data-download/explorer-data`, {
    headers: { Authorization: `Bearer ${token}`, Accept: "application/json" }
  });
  if (!res.ok) {
    console.warn(`explorer-data fetch failed: ${res.status}`);
    return [];
  }
  return await res.json();
}

What you will learn next

Each lesson is short and uses your own data. You will learn to answer everyday questions:

  • 🔎 Find the rows you need — “Show me only the landings from Vanga.” — “Only last month.”
  • 📋 Pick the columns you need — “I only want the date, the site and the weight.”
  • ➕ Add it up — “What is the total catch at each site?” — “Which gear catches the most?”

You will only ever press Run and change small things. Take the lessons in order.
