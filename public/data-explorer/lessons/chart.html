Lesson 5 of 5 · about 15 minutes

What this lesson is for

A table of numbers is hard to talk about in a meeting. A picture is not.

In this lesson you turn one of your own totals into a simple bar chart. It is the kind of picture you can put in a report, or show to a supervisor. It takes one new command.

Press Run on each box. Remember: you cannot break anything.

Before we start

The box below loads the small example table, the same five rows as the last lesson. It runs on its own when the page opens, so you do not have to do anything with it.

If nothing happens at first, R is still waking up — up to a minute the first time, on a slow connection. A small spinning circle on a box means it is working. Wait for it to stop.

Your own landing records are fetched at the same time, under the name landings, so they are ready by the time you need them further down the page.

landings_state = {
  landings_reload;

  yield ({ phase: "loading" });

  const token = localStorage.getItem("authToken");
  if (!token) {
    yield ({ phase: "signed-out" });
    return;
  }

  const apiBase = localStorage.getItem("apiBaseUrl") || "/api";
  try {
    const res = await fetch(`${apiBase}/data-download/explorer-data`, {
      headers: { Authorization: `Bearer ${token}`, Accept: "application/json" }
    });
    if (!res.ok) {
      yield ({ phase: res.status === 401 || res.status === 403 ? "signed-out" : "failed" });
      return;
    }
    // The endpoint returns a bare array. Normalising anyway: `rows.length` is read straight into the
    // panel text, so anything else here would throw and take the whole panel down with it.
    const rows = await res.json();
    const safeRows = Array.isArray(rows) ? rows : [];
    // Absent on an older deployment; the panel then just omits the sentence about the cap.
    const cap = Number(res.headers.get("X-Row-Cap"));
    mutable landings_rows = safeRows;
    yield ({ phase: "ready", rows: safeRows, cap: Number.isFinite(cap) && cap > 0 ? cap : null });
  } catch {
    yield ({ phase: "failed" });
  }
}

A chart is just a table, drawn

The last lesson ended with a table of totals. A chart shows the same numbers, drawn as bars. Nothing new is calculated. So a chart is always two steps.

Step one: work out the totals, exactly as you did last lesson, and give them a name. Here that name is totals. Press Run:

What you should see: two rows. Shimoni 20 kg and Vanga 14 kg. Nothing has been drawn yet. You have only given the answer a name, so you can use it again in the next box.

Step two: draw it. Every box from here on uses the totals table you just made, so run the box above first. If you ever see object 'totals' not found, that is all it means.

The command is barplot(), and it needs two things:

  • the heights of the bars, totals$total_kg
  • the labels under them, totals$gaul_2_name

Remember the $ sign from the first lesson. It means “this column of that table”.

Before you run it, have a guess.

Make it fit to show someone

The bars are right, but a chart nobody can read is no use in a report. Three settings fix that. Each one is just a word and a value:

  • main = puts a title on top
  • ylab = labels the side, so the reader knows the numbers are kilograms
  • col = sets the colour

Press Run, then try changing the title, or the colour to "darkgreen":

What you should see: the same two bars, now blue, with a title above and “Kilograms” down the side.

This is the version you would paste into a report. Nothing about the numbers changed. You only made them easier to read.

Now your own data

Time to draw your own records. A useful first question: which gear brings in the most?

It is the same two steps. Work out the totals, then draw them.

One thing to know first. A chart needs numbers to draw. If there is nothing to draw — because you are not signed in, or your records came back empty — these last boxes show red text instead of a picture.

The last line will read need finite 'xlim' values. It looks alarming, but it is only barplot saying “you gave me an empty table, so I cannot tell how wide to make the picture.” A few warnings about min and max may appear above it. Ignore those and read the last line, as always.

Nothing is broken. Open this lesson from the Data Explorer tab while signed in, and the charts will appear.

Step one, the totals. Press Run:

Step two, the picture. Gear names are long, so this one adds las = 2, which turns the labels sideways to make room for them. Press Run:

What you should see: one bar for each fishing method in your records, with the tallest bar showing the gear that brings in the most weight.

If the labels look cramped, that is normal on a small screen. Try removing las = 2 and pressing Run again to see the difference it makes.

Your turn: chart something else

Now you choose what to draw. The box below is the same two steps, with the column blanked out. Replace both ______ with the same column name, then press Run.

Press Hint if you would like a suggestion.

Any column that holds words rather than numbers will work. Good ones to try:

  • gaul_2_name — one bar for each district
  • catch_taxon — one bar for each kind of fish

Put the same name in both blanks.

If you choose catch_taxon you may get a great many bars, because there are many kinds of fish. That is not a mistake. It is a sign that a chart with fewer groups, like gaul_2_name, is easier to read.

my_totals <- landings |>
  group_by(gaul_2_name) |>
  summarise(total_kg = sum(catch_kg, na.rm = TRUE))

barplot(
  my_totals$total_kg,
  names.arg = my_totals$gaul_2_name,
  main      = "Total catch by district",
  ylab      = "Kilograms",
  col       = "steelblue",
  las       = 2
)

What you have learned

  • A chart is a table, drawn. Always two steps: work out the totals, then draw them.
  • barplot(heights, names.arg = labels) draws the bars.
  • main =, ylab = and col = make it fit to show someone.
  • las = 2 turns the labels sideways when the names are long.

And one idea worth keeping: a chart never calculates anything. It only shows the numbers you already worked out, so if a bar looks wrong, check the totals table above it.
